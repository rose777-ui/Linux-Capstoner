# 🐧 Linux Capstone Project – Phase 1

## 📖 Overview

This repository contains my **Linux Phase 1 Capstone Project**, completed as part of my Linux and Cyber Security learning journey. The project focuses on Ubuntu fundamentals, Linux system administration, command-line usage, user management, file permissions, networking, security, Git, and Bash scripting.

The goal of this project is to build a strong foundation in Linux administration and prepare for advanced Cyber Security topics.

# 📜 Bash Script

The project includes a Bash script named **system_report.sh**.

It displays:

- Hostname
- Current User
- Date & Time
- Ubuntu Version
- Kernel Version
- Memory Usage
- Disk Usage
- IP Address
- System Uptime

Run the script:

```bash
chmod +x system_report.sh
./system_report.sh
```

---

# 🔥 Firewall

Basic UFW commands:

```bash
sudo ufw enable
sudo ufw status
sudo ufw allow OpenSSH
```

---

# 🔐 SSH

Install SSH Server

```bash
sudo apt update
sudo apt install openssh-server
```

Check status

```bash
sudo systemctl status ssh
```
