# Module 1.1 – Ubuntu Installation Mastery

## Overview

This module explains how to install Ubuntu safely on a physical computer or virtual machine and introduces concepts such as LTS releases, ISO images, partitioning, and boot modes.

---

## Learning Objectives

After completing this module, I can:

- Explain Ubuntu editions.
- Download Ubuntu ISO safely.
- Verify ISO using SHA256.
- Install Ubuntu on VirtualBox.
- Understand GPT and MBR.

---

## Ubuntu

Ubuntu is a free and open-source Linux operating system based on Debian.

### Advantages

- Free
- Secure
- Stable
- Large community
- Suitable for Cyber Security

---

## Ubuntu LTS

LTS stands for Long Term Support.

Features

- 5 years of support
- Security updates
- Stable
- Recommended for beginners

---

## Ubuntu Desktop

Provides a graphical user interface (GUI).

Used for

- Learning Linux
- Development
- Everyday computing

---

## Ubuntu Server

Server edition has no desktop environment.

Used for

- Web servers
- Database servers
- Cloud computing

---

## ISO Image

An ISO file contains the installation files for Ubuntu.

---

## Bootable USB

A USB drive prepared with an operating system installer.

---

## GPT vs MBR

| GPT | MBR |
|------|------|
| Modern | Legacy |
| Supports large disks | Up to 2 TB |
| Recommended | Older systems |

---

## ext4

The default Linux filesystem.

Advantages

- Fast
- Stable
- Reliable
